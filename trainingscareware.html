Deceptive warning (“scareware”) demonstration

Press the button to display a full-screen fake warning. Ask the class to practice closing it the right way instead of clicking anything inside it.

Before you press it

  1. Tell the room this is a demonstration — the yellow bar stays visible the whole time, on purpose.
  2. Warn that there is an alarm sound if you leave it switched on below.
  3. The correct exit is Esc here, and Alt+F4 for a real browser window. If a real page blocks both, Ctrl+Shift+Esc opens Task Manager → select the browser → End task.
  4. Nothing on the warning screen is clickable in a way that does anything. The buttons are there to be not clicked.

Debrief — what pressured you

The screen was up for 0 seconds. Walk the class back through the tactics they just felt:

  • It filled the screen so the real browser — tabs, address bar, close button — disappeared.
  • It counted down. A deadline exists to stop you asking a coworker.
  • It gave you one action: call a number. Real security software never asks you to phone anyone.
  • It borrowed authority with an official-sounding name, an error code, and a lock icon.
  • It made noise, which is embarrassing in a room with a patient in the chair — and embarrassment makes people act fast and quietly instead of asking for help.

What none of it could do: stop Alt+F4, or stop you walking down the hall to tell your office manager.
